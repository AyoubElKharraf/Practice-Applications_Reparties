# 🚀 Practice-Application_Réparties

Ce dépôt regroupe l'ensemble des Travaux Pratiques (TPs) et des projets de mise en pratique dans le domaine des **Applications Réparties** et des architectures distribuées. Il couvre différentes technologies et paradigmes de communication réseau, allant de la programmation bas niveau en C jusqu'aux technologies orientées objets en Java.

---

## 📂 Structure du Dépôt

Le projet est organisé par modules de TP progressifs :

```text
Practice-Application_Réparties/
│
├── TP 1 - Socket C/
│   ├── Images/
│   ├── tp1_socket_c/
│   ├── pipeline.txt
│   └── TP1.pdf
│
├── TP 2 - Socket C en mode Datagramme (UDP)/
│   ├── client_chat.c
│   ├── serveur_chat.c
│   ├── Makefile
│   ├── Rapport_TP1_Sockets_C.docx
│   └── TP2 Sockets C en mode Datagramme.pdf
│
├── TP 3 - RPC/                      # Appels de Procédures Distantes (RPC)
├── TP 4 - Socket JAVA/              # Programmation réseau orientée flux/datagrammes en Java
└── TP 5 - RMI JAVA/                 # Remote Method Invocation (Java RMI)
```
